# MAPLE — Model-Agnostic Platform for Laboratory Experiments

LLM agents for autonomous experiment execution on [MADSci](https://github.com/AD-SDL/MADSci) laboratories via the Model Context Protocol.

> 🚧 Under active development. v0.1.0 coming soon.

## Quick Start

```bash
pip install maple-mcp
cp .env.example .env  # configure MADSci URLs + LLM API key
maple serve --all
maple chat --agent overseer
```
